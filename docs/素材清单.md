## 1. 授权速查

| 级别 | 授权 | 能不能商用 | 要不要署名 |
|---|---|---|---|
| 🟢 最干净 | **CC0 1.0** | 可以，无限制 | 不需要（作者普遍希望你署名，但无义务） |
| 🟢 最干净 | **MIT / OFL 1.1** | 可以 | 保留授权文件即可 |
| 🟡 可用 | **CC-BY 4.0** | 可以 | **必须署名**（游戏内"素材致谢"页） |
| 🔴 避开 | **CC-BY-SA 3.0 / GPL 3.0**（LPC 系） | 可以 | 必须署名，且**衍生作品必须同样开源**（传染） |
| 🔴 避开 | **无授权 / 自定义收费授权** | 看合同 | 例如 Zpix 商用要 ¥7000 |

## 5. 字体（最容易踩坑的一栏）

| 字体 | 授权 | 商用 | 核验 | 说明 |
|---|---|---|---|---|
| **[方舟像素字体 Ark Pixel Font](https://github.com/TakWolf/ark-pixel-font)** | **MIT** | ✅ 免费商用 | ✅ GitHub API 确认 `spdx_id: MIT`；[官网](http://ark-pixel-font.takwolf.com/) | 泛拉丁 + 泛中日韩，12px/16px 多字号。**中文像素游戏首选** |
| **[缝合像素字体 Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font)** | **MIT** | ✅ 免费商用 | ✅ GitHub API 确认 `spdx_id: MIT`；[官网](http://fusion-pixel-font.takwolf.com/) | 同上，风格更接近"缝合"多款像素字体，字符集更全 |
| [Cubic 11 俐方體 11 号](https://github.com/ACh-K/Cubic-11) | **OFL 1.1**（实测原文「任何人可以無償使用此字型，包含商用」） | ✅ | ✅ 已核实 OFL.txt 原文 | 11px 繁体。**坑**：最新 release `v1.500` 的 assets 数 = 0（发布页没有字体附件），字体只在仓库里 → 用 `https://cdn.jsdelivr.net/gh/ACh-K/Cubic-11@1.500/fonts/ttf/Cubic_11.ttf` |
| ⚠️ [Zpix 最像素](https://github.com/SolidZORO/zpix-pixel-font) | **自定义收费授权** | ❌ **商用要 ¥7000 / $1000** | ✅ 本次抓取其 README 确认 | 个人/教育免费，商用单产品 ¥7000。**这是本清单里最大的一个坑**，很多教程会无脑推荐它 |

> Zpix 的原文（来自其 README）：
> 「用于 单个商业产品 - **RMB ￥7000**」「用于 个人项目 - **免费**」「禁止对本字体进行修改、反编译、转换、拆分」
>
"> **所以：练手/个人项目可以白嫖 Zpix，一旦想上线卖钱，请换成 MIT 的方舟或缝合像素字体。**
>
> 补充实测细节：
> - Zpix **仓库根目录没有 LICENSE 文件**，条款只写在 README 正文里 —— 这类"授权只存在于文档"的素材最容易踩坑。
> - 它还**禁止修改/转换/拆分**（所有授权版本均不允许），意味着你连子集化都不该做。
> - **Ark Pixel 的 16px 已废弃**（README 明文，最后含 16px 的版本是 2026.09.01），现在是 10px/12px × monospaced/proportional —— 别照抄旧教程。
> - **Fusion Pixel 是多许可证混合**：根目录 `LICENSE-OFL` + `LICENSE-MIT`，而 `assets/fonts/` 下每个被缝合的字体各带自己的 OFL/LICENSE（ark-pixel / boutique-bitmap / cubic-11 / galmuri / misaki / miseki）→ 发版时要把这些许可文本一并保留。
> - Fusion 的 TTF 包 26–47 MB（含全语言子集），**上线前必须 pyftsubset 子集化**。

本项目当前用的是**系统字体兜底**（`ui-monospace, PingFang SC, ...`），因为内部渲染分辨率只有 480×270，
文字是随画面一起整数倍放大的。想要更纯的像素味，把上面任一 MIT 字体的 woff2 放进项目、在 `index.html`
里 `@font-face` 声明，再把 `src/app.js` 的 `FONT` 常量换成它即可。

## 7. 推荐最小组合（实测过的版本）

**极限 4 包**（覆盖全部美术 + 音效 + 字体，全是 CC0/OFL，署名工作量 0、零 share-alike）：

1. **[Kenney Roguelike Caves & Dungeons](https://kenney.nl/assets/roguelike-caves-dungeons)**（CC0，184 KB）
   → **一个包吃下"矿石块 + 矿洞 tileset"**。实测解包：16×16 spritesheet 492×305，
   包内 `spritesheetInfo.txt` 原文「tiles are 16 x 16px and have a 1px margin」。
2. **[Kenney UI Pack - Pixel Adventure](https://kenney.nl/assets/ui-pack-pixel-adventure)**（CC0，309 KB，500 文件）→ 面板/按钮/进度条
3. **Kenney Interface Sounds + Impact Sounds**（CC0）→ 实测解包分别 100 / 130 个 `.ogg`
4. **[Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font)** 12px Proportional（OFL-1.1）→ 中文覆盖最广

**再加 2 个就更舒服**：[Kenney Tiny Dungeon](https://kenney.nl/assets/tiny-dungeon)（矿工 + 木梁道具，132 个 16×16 PNG）、
[Kenney Cursor Pixel Pack](https://kenney.nl/assets/cursor-pixel-pack)（16×16 光标 + 心/骷髅/火焰图标）。

**为什么把 0x72 DungeonTileset II 从首选降级**：它风格最契合（含 idle/run/hit 动画角色），
但**本机 itch.io 全系不可达，无法直连核验授权**。若你能访问 itch，建议二次确认后纳入。

**⚠️ 三个"体积/风格"陷阱**：
- Kenney 的 **Particle Pack（14.6 MB）/ Smoke Particles（5.9 MB）是 512×512 高分辨率贴图**，
  直接进像素游戏会风格崩坏 → 必须最近邻降采样到 ≤32×32 并限色；**体积敏感就换成 OGA 的 `Pixel FX Pack`（CC0，KB 级、像素原生）**。
- 9-slice 最全的是 **OGA 镜像的 Kenney `Pixel UI pack (750 assets)`**，内含独立 `9-Slice/` 目录
  （Ancient/Colored/Outline × brown/grey/tan/white × base/_inlay/_pressed）。
- **Kenney "Music Loops" 官方页实测 404**（网上流传的 `gamesounds.xyz` 是第三方镜像，不是官方）
  → 循环 BGM 请用 OGA 的 CC0 曲（Dungeon Ambience / Crystal Cave）。

**调色板可以直接抄这个**：Lospec **Dungeon-20**（hex 实测取自 Lospec 的 `.json` 端点）：
`2e222f 45293f 7a3045 993d41 cd683d fbb954 28353e 344a5a 407080 508da0 5bbfc5 f2ec8b b0a987 997f73 665964 443846 576069 788a87 d6dad3 a9b2a2`
（深处想做出"色相漂移"可以切 **Cyan Abyss**）。

**矿石块的最优解不是找 8×8 图**：OGA 的 **CC0 Gem Icons**（AntumDeluge）包内实测有 `32x32/` 与 `34x34/` 两套独立 PNG，
含 ruby/sapphire/jade/amethist/opal/diamond/crystal_01-03/agate 共 11 种 → 取 5 种颜色即得"色 + 形双编码"的消除块（色盲友好），
最近邻降到 16×16 即可。原生 8×8 的只有 OGA `8x8 cave platformer set`（CC0）。

**关于 LPC（Liberated Pixel Cup）—— 别一刀切**：
- 项目主页 <https://lpc.opengameart.org/> 实测原文是「dual licensed under **CC BY-SA 3.0** and **GPLv3**」，
  两者都带 copyleft ✓（我原先"避开 LPC"的判断在这一点上是对的）。
- **但有重大例外**：逐页看 `License(s)` 会发现部分条目的授权清单里含 **OGA-BY 3.0**（无 SA），例如
  `[LPC] Dungeon Elements` 实测为 `CC-BY 4.0/3.0, GPL 3.0/2.0, OGA-BY 3.0`（**没有 SA**），
  `[LPC Revised] Character Basics!` 也含 OGA-BY 3.0 选项 → **可以安全按那一档使用**。
- 结论：**LPC 标签 ≠ 一定传染，必须逐页看 License(s) 并选非 SA 那一档。**

**另外两个"以为能用其实不能用"的音频工具**（实测）：
- DrPetter 原版 sfxr 官网 `drpetter.se/project_sfxr.html` 现已返回托管商的 **"Blocked Page"（失效）**；
- **Bfxr** 的 GitHub 仓库 `increpare/bfxr` 经 API 查得 **license: None**、站点无明文条款 → 授权不明确。
- → 统一改用 **jsfxr**（<https://sfxr.me/> 功能表明确勾选「Unrestricted commercial use」；源码 `chr15m/jsfxr` = Unlicense）。
- ChipTone 原站只剩"has a new home"跳 itch，而 itch 本机不可达 → **未验证**。

## 8. 自研方案（本项目的做法，可直接复用）

不想被授权问题纠缠的话，自研其实**比找素材更快**：

- **尺寸**：8×8 一个精灵，盘面按整数倍（3×）放大 → 保证像素锐利，永不糊。
- **形状即身份**：5 种矿石用 5 种**不同轮廓**（圆/三角/菱形/星/方），颜色只是装饰。
  这是**色盲可玩性**的关键，也让"用调色板换皮"变成零成本操作。
- **位图用字符串写**：一个精灵就是 8 行 8 字符的字符串数组（`0` 透明，`1-4` 明度）。
  改一个像素就是改一个字符，**不需要打开任何绘图软件**，还能被代码直接渲染、被脚本导出成 PNG。
- **工具链**：`tools/sheet.js` 用一个"假 canvas"喂给真实渲染代码，把精灵导出成
  `assets/ores-sheet.png`（8 倍放大，可直接拿去当素材用）。
- **想手绘时**：
  [Pixelorama](https://github.com/Orama-Interactive/Pixelorama)（**MIT**，实测最新 v1.2.3 / 2026-09-15 —— **免费首选**）、
  [Aseprite](https://www.aseprite.org/)（$19.99，像素画标杆）、
  [LibreSprite](https://libresprite.github.io/)（GPL 分支）、
  [Krita](https://krita.org/)（免费）、
  [Piskel](https://www.piskelapp.com/)（网页版，零安装）。
  注意 `pixelorama.app` 与 itch 页在本机不可达，走 GitHub Releases。
